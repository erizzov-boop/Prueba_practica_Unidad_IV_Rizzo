# Prueba_practica_Unidad_IV_Rizzo
### Ingeniería de Requisitos — Caso: Sistema de Gestión de Pedidos

Este repositorio contiene el desarrollo completo en LaTeX de las actividades *P1 a P10*
de la Prueba Práctica de la Unidad IV de la asignatura ISR-401, incluyendo los diagramas
